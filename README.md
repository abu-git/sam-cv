# Samuel Abu - Portfolio

A digital portfolio for Samuel Abu, a developer and creative. Built with a focus on smooth animations, handwritten typography, and a warm, personal aesthetic.

Live site: [https://sam-cv.vercel.app/](https://sam-cv.vercel.app/)

## Features

- **Modern Stack:** Built on Next.js 15 (App Router), React 19, and Tailwind CSS.
- **Theming:** Seamless light and dark mode toggling powered by `next-themes`.
- **Animations:** Smooth, cascading scroll animations and micro-interactions using Framer Motion.
- **Typography:** Custom handwritten font (Shadows Into Light) optimized via `next/font`.
- **Contact Form:** Server-side email delivery via SendGrid (currently migrating to Resend).
- **Floating WhatsApp Widget:** Lightweight, custom-built chat widget for direct inquiries.
- **Responsive Design:** Fully fluid layout with a custom mobile navigation drawer that locks body scroll and traps focus.

## Tech Stack

- **Framework:** [Next.js 15](https://nextjs.org/) (App Router)
- **Library:** [React 19](https://react.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animation:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Heroicons](https://heroicons.com/), [Lucide](https://lucide.dev/), [React Icons](https://react-icons.github.io/react-icons/)
- **Email:** [SendGrid](https://sendgrid.com/)
